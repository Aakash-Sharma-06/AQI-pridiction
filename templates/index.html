About this project

From readings to a useful estimate

A compact machine-learning workflow built to make experiments with air-quality data easier to understand.

01

Prepare the data

The training pipeline detects a target, excludes target leakage, derives date features, filters invalid sensor readings, and imputes missing values.

02

Compare models

Regression and classification models are evaluated on a held-out test split. The best model for each task is saved for the web app.

03

Explore a scenario

Submit readings to estimate a target value and category. Use the model insights tab to inspect metrics, feature influence, and training charts.

ⓘ

Important: These are model estimates based on the provided training dataset, not live sensor measurements or health advice. Follow local air-quality advisories for decisions.
